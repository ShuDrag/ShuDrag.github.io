Twikoo 评论系统部署教程

发表于 2026-05-16 分类于 Hexo 阅读次数：

博客搭建起来之后，为了配置评论功能，对比了一圈，其中 Twikoo 是适合自己的

主要有以下几点

  • 开源，免费，轻量无广告
  • 匿名性好，用户评论无需登陆（非常重要‼️）
  • 可收到邮箱 / 即时消息通知
  • 国内可访问

大致的部署思路是 MongoDB + Vercel (官方主推，零成本 Serverless)，这是绝大多数静态博客用户的选择，完全免费，且不需要自己维护服务器

准备数据库 (MongoDB Atlas)

  • 注册 MongoDB 云服务，创建一个免费的集群（Free Tier）
  • 获取数据库的连接字符串（URI），类似mongodb+srv://user:password@cluster...

进入一个 Projects，在 Database Access 页面点击 add New Database User 创建数据库用户


在 Password Authentication 下设置数据库用户名和密码，点击 Auto Generate 自动生成一个强密码并保存

Built-In Role，Select Role 选择 Atlas Admin，最后点击 Add User

在 IP Access List 页面点击 Add IP Address 添加网络白名单, 输入 0.0.0.0 / 0（允许所有 IP 地址的连接）

在 Database 页面点击 Connect，连接方式选择 Drivers，并记录数据库连接字符串，将字符串中的 : 修改为刚刚创建的数据库用户名:密码



连接字符串至关重要，它囊括了连接至 MongoDB 数据库的全部必要信息。一旦该字符串不慎泄露，后果将十分严重。
因此，务必妥善保管好这一连接字符串，在后续对 Twikoo 进行部署时，还需要将其准确填入到相应的部署平台中
到这里 MongDB 的部署就完成了

一键部署后端 (Vercel)

  • 登录 Vercel，通过 Twikoo 官方提供的 “一键部署” 按钮，将 Twikoo 的后端代码克隆到你的 GitHub 并自动部署到 Vercel
    Twikoo 一键部署
  • 在 Vercel 的项目环境变量（Environment Variables）中，添加一条MONGODB_URI，值为前面 MongoDB 的数据库连接字符串
  • 进入 Deployments，进行 Redeploy，等待重新部署完毕
  • 等待重新部署完成后，进入 Project，查看 Overview 或者点击 visit，看见下面的提示，说明部署成功

绑定域名与获取 envId

  • Vercel 部署后会分配一个二级域名（例如 twikoo.vercel.app），可能已经被国内污染了，无法正常访问,
    可以绑定自己的自定义域名
  • 这个域名就是你在 Hexo 中填写的envId
