本地群晖部署 Memos 并嵌入 Hexo 做说说

发表于 2026-05-22 分类于 Hexo 阅读次数：

一直想给静态的 Hexo 配置一个说说的功能，查看了一些教程，都推荐接入 Artitalk 配合 LeanCloud 数据库，但是发现 LeanCloud 停止服务了

于是又找到了 Memos，摸索了一下，这里做个记录
总体思路是通过本地群晖 docker compose 部署 Memos，用 cloudflare 的 Tunnel 功能解决内网穿透与 SSL 证书问题，再通过 Memos 自带的开放 API 异步加载到 Hexo 中
