thelounge 安装教程

发表于 2022-05-01 分类于 教程 阅读次数：


thelounge 是一个全平台的 IRC 客户端，对与玩外站的玩家来说，IRC 是必须要用到的工具，下面是在 linux 下通过的 Docker 的方式安装：

首先 vps 上先安装 docker：

按提示进行


docker 安装完成后，手动创建容器:


刚安装完是默认没有用户的，所以需要创建一个用户。进入容器内创建账户


到此命令行安装过程结束，浏览器打开网址：

http://localhost:9000

登录进去打开后，点击左下角齿轮标志进入设置，勾选第一行 Advanced settings 以展开所有设置


设置项是即时生效的，无需保存。
